# Pares POS

Simple offline-first POS for a single device. Data is stored in the browser via `localStorage` (menu + sales).

## Run

```bash
npm install
npm run dev
```

## Build + Preview

```bash
npm run build
npm run preview
```

## Data Storage

All app data is stored locally in `localStorage` on the device (menu + sales). Clearing site data will reset the app.
